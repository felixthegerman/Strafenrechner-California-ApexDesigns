NEW YORK STRAFRECHNER – START & KOSTENLOSE VERÖFFENTLICHUNG
===========================================================

LOKAL STARTEN
ZIP entpacken und index.html öffnen. JavaScript muss aktiviert sein.

GITHUB PAGES
1. Kostenloses GitHub-Konto und öffentliches Repository erstellen.
2. Alle Dateien dieses Ordners hochladen; index.html muss im Hauptordner liegen.
3. Settings > Pages > Deploy from a branch wählen.
4. Branch main und /(root) auswählen und speichern.

CLOUDFLARE PAGES
Workers & Pages > Create application > Pages > Direct Upload öffnen und den
entpackten Ordner hochladen.

BEDIENUNG
- DE/EN schaltet die gesamte Oberfläche um.
- Rechner: 268 New Yorker Einträge durchsuchen, mehrfach hinzufügen und exportieren.
- Strafzettel: VTL-, Park-, Fahrrad-, Motorrad- und Bootsverstöße auswählen und PDF erstellen.
- Berichte: Behörde und Berichtstyp wählen; Straftaten sind optional und eigene
  Texte können ergänzt werden.
- Webhooks müssen bei öffentlichem Hosting sicher im Backend gespeichert werden.
